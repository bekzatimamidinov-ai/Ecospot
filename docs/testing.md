# Тестирование EcoSpot

## Подход

- **Автоматические тесты API** (pytest + FastAPI TestClient): 54 теста, охватывают функциональные требования этапа 1 и критерии приёмки из раздела 15 ТЗ.
- Тесты работают на **отдельной базе PostgreSQL `ecospot_test`**. Перед каждым тестом база пересоздаётся и заполняется демо-данными, поэтому тесты независимы друг от друга.
- **Ручное тестирование интерфейса** по сценариям UC-01 … UC-05 (таблица ниже).

## Запуск

```bash
cd backend
.venv\Scripts\activate
pip install -r requirements-dev.txt
pytest                                   # подробный вывод в консоль
pytest --html=../docs/test-report.html --self-contained-html   # HTML-отчёт
```

В VS Code: `Terminal → Run Task → Запустить тесты` или вкладка **Testing** (колба слева).

Перед первым запуском нужна тестовая база:

```sql
CREATE DATABASE ecospot_test OWNER ecospot ENCODING 'UTF8' TEMPLATE template0;
```

## Ручные тест-кейсы интерфейса

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Регистрация | Открыть «Регистрация», заполнить форму | Вход выполнен, открыт личный кабинет |
| TC-02 | Сообщение о проблеме (UC-01) | Войти как user@ecospot.kg → «Сообщить о проблеме» → заполнить, кликнуть по карте, приложить фото → «Отправить» | Карточка со статусом «Ожидает проверки» и предупреждением «не подтверждено» |
| TC-03 | Модерация (UC-02) | Войти как mod.leninsky@ecospot.kg → «Модерация» → открыть сообщение → «Подтвердить» | Статус «Подтверждена», запись в истории проверки, автору пришло уведомление |
| TC-04 | Отклонение без причины | В панели модерации нажать «Отклонить» с пустым комментарием | Ошибка «Укажите причину отклонения» |
| TC-05 | Подписка (UC-05) | Личный кабинет → отметить район → «Сохранить» → другим пользователем создать проблему в этом районе | Колокольчик показывает новое уведомление, по клику — переход к карточке |
| TC-06 | Мероприятие (UC-03) | Войти как organizer@ecospot.kg → карточка подтверждённой проблемы → «Создать мероприятие» | Мероприятие на карте и в списке, проблема «Запланирована к устранению» |
| TC-07 | Лимит участников | Создать мероприятие на 1 человека, записаться двумя пользователями | Второму — «Мест нет» |
| TC-08 | Завершение мероприятия | Организатор: «Начать выполнение» → ввести отчёт → «Завершить» | Мероприятие «Завершено», проблема «Устранена» |
| TC-09 | Мобильная версия | Открыть сайт в режиме телефона (F12 → значок устройства) | Меню-бургер, карта и списки в одну колонку |
